# ukr2022-osm-data

Выгрузка OpenStreetMap по югу Украины (30.9–38.6° в. д., 44.3–48.2° с. ш.) для игры «Україна, 24.02.2022».

Сборка `.github/workflows/extract.yml` запускается сама при каждом изменении `extract/` или workflow:

1. скачивает снимок OSM Украины с Geofabrik на 01.01.2022 (если его нет, то на 01.01.2023, иначе самый свежий);
2. вырезает юг (`osmium extract`), оставляет нужные теги (`osmium tags-filter`);
3. выгружает в GeoJSON (`osmium export`) и упаковывает в компактные части `extract/pack.py`;
4. кладёт результат в ветку `data`: `data/osm_partN.json.gz` (дороги, ж/д, вода, леса, лесополосы, застройка, населённые пункты) и `data/bld_partN.json.gz` (здания).

Формат строки: `[класс, id, имя, геометрия, флаги]`. Геометрия — целые числа в 1e-5° (первая точка абсолютно, далее приращения); полигон — `{"o": [кольца], "i": [дыры]}`.
